# Codex Rescue Kit v0.1.0-preview.1

This is a **source preview** to invite community review and diagnostics feedback, not a verified automated repair distribution.

Highlights: independent `rescue.cmd` defaulting to Diagnose, narrow static environment metadata collection, optional Codex Skill, per-file backup verifier, source-visible transaction prototype, synthetic regression evidence.

Important limitation: **live Quarantine/Undo are blocked** by new entry and function gates (`PREVIEW_REAL_MUTATION_DISABLED`, exit 3). The underlying implementation remains available for source inspection and synthetic fixture tests. The four non-elevated entry refusal checks passed on Windows PowerShell 5.1.26100.9711 and PowerShell 7.6.5; each engine also passed 73 synthetic cases, static checks and a synthetic default Diagnose entry check. Skill structure validation passed. These checks are not live recovery or full active data-tree acceptance.

Known gaps: no real Task Scheduler/HKCU Run/COM modification trials; no real desktop Codex A/B/C attribution and sandbox-boundary validation; no login or real history recovery testing. Baseline evidence belongs to the `e7ce4f5` lineage and is not a verification of the new public-preview changes.
