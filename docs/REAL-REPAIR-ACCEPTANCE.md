# 收敛的实际修复验收与最小真实 API 清单

本候选停在本地代码/合成执行证据，尚无授权备用 Windows 用户环境。完整 VM 不是开发前置条件。以下真实步骤独立列为 NOT_TESTED，不能拿合成结果替代。

## 核心五项

| 项 | 证据 | 当前开发机状态 |
|---|---|---|
| 历史还在且代表性旧对话可读 | 私有备份清单 + 官方 GUI 手动打开阅读，带时间/会话引用，内容脱敏 | 真实 NOT_TESTED；合成未改历史文件 |
| 资产与原项目保全 | 备份范围/未覆盖项、前后资产哈希、显式项目检查；Git/Worktree 不覆盖 | 合成已测；真实 NOT_TESTED |
| 官方登录且新会话可发消息 | 用户本人 OAuth/官方 UI，新会话实际发送和模型返回 | NOT_TESTED |
| 原项目新会话实际工具可用 | B：实际 Codex 工具运行三次独立命令、exit code、受控 canary、原项目绑定及来源审阅；C：独立普通宿主核对 | NOT_TESTED |
| 接管未复发 | 已确认入口/进程状态、至少 60 秒 config hash+mtime；本人重启后重复，boot/冷启动证据 | 合成窗口已测；真实与重启 NOT_TESTED |

旧会话不能继续发送是接受的兼容性限制，不影响上述五项满足后的恢复结论；不要求唯一根因，不改旧 DB/provider，不引入内部别名。外部审阅五项全部通过才可由人确认 RECOVERED_VERIFIED；工具缺来源/GUI证据时保持 PARTIAL_RECOVERY/NOT_TESTED。

## 最小真实 Windows API 验收（不要求完整 VM 项目）

先取得一台非生产 Windows 11 x64/NTFS、独立普通测试用户或备用环境的精确授权：用户名/SID、home、输出、快照/还原点、唯一对象名称、脚本绝对路径、PID/创建时间、可中断对象和强停风险。管理员及重启另行授权。当前现用用户不允许执行这些注入。

1. 仅在独立测试用户创建一个新的无害持续 writer 和一项当前 SID 的 Task、一个唯一 HKCU Registry64 String Run 值、一条同卷 Startup .lnk；保存精确定义。不得复用现有真实启动项。运行中的任务验证 Settings.Enabled，不能用 State 判启用。
2. 读取真实归属/命令/PID身份/哈希，批准唯一修复计划，单独批准必要强停；确认进程已退出、任务配置被禁用、该 Run 值不存在、仅该快捷方式被移入私有区。
3. 验证备份包含 config/auth、sessions/归档/SQLite+WAL/SHM/Skills/Rules/AGENTS，manifest全覆盖、哈希和 ACL；模拟读锁/不足空间只能用新建测试文件，不锁真实 DB。无一致性证明不宣称干净还原。
4. 在测试 home 隔离指定配置/auth，不触及其余资产；原生进程身份复用或 definition/writer 漂移必须拒绝。新建同名目标/新登录文件必须让 Undo 冲突停止，不覆盖。
5. 以测试事务验证中断后的 Resume/Undo，原 Task/Run/lnk定义恢复，进程内存不恢复。所有后续测试对象清理由人按精确清单决定，工具不自动删除。
6. 官方 GUI/模型/B 工具和重启按核心五项人工验收；历史样本必须是合法授权的数据，不把本地文件存在作为 GUI 可读证据。
7. Sandbox 有精确匹配时，单独批准单对象 owner-only 人工变更；读回 owner+DACL，复测真实工具。无匹配则 BLOCKED，禁止循环放宽权限。

## 威胁模型与限制

保护对象：配置/认证、历史 DB/会话、项目、Skills/Rules、无关进程及启动项。威胁包括误归属、持续 writer、PID复用、状态漂移、半完成写入、备份不一致、磁盘不足、重解析路径、撤销覆盖和日志秘密外泄。约束为本地普通用户、显式目标/批准、私有受限新目录、SHA256/Journal、同卷移动和不覆盖。

同用户恶意进程或管理员能修改计划/Journal/审批输入及运行时，哈希链不是签名或隔离安全边界。扫描与操作仍存在 OS 竞态；进程 handle/starttime 缩小 PID竞态，文件/任务/Registry 无跨对象原子事务。无法归属的复杂 runner 不猜测处理；未识别写入者、企业管理设备、额外用户/磁盘、网络 home、完整数据库还原、真实冷启动及所有工具 sandbox 后端不在已测结论内。出现具体不确定性只补最小针对检查，不重新打开未受影响旧问题。
